# Markdown flavor compatibility

| Feature | GitHub | Obsidian | Jupyter | Discord | Slack |
| --- | --- | --- | --- | --- | --- |
| Bold `**text**` | Yes | Yes | Yes | Yes | No, use `*text*` |
| Italic `*text*` | Yes | Yes | Yes | Yes | Use `_text_` |
| Strikethrough | `~~text~~` | `~~text~~` | `~~text~~` | `~~text~~` | `~text~` |
| Tables | Yes | Yes | Yes | No | No |
| Task lists | Yes | Yes | Limited | No | No |
| Footnotes | Yes | Yes | Limited | No | No |
| Math | No, unless enabled | Yes | Yes | No | No |
| Mermaid | In some views | With a plugin or core | No | No | No |
| Callouts | `> [!NOTE]` | `> [!note]` | No | No | No |
| Wikilinks | No | Yes | No | No | No |

When a feature is missing, convert with the matching tool on MarkdownTools instead of hoping the destination will guess.
