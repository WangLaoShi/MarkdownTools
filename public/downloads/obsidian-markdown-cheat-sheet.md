# Obsidian Markdown cheat sheet

## Wikilinks

```md
[[Note]]
[[Note#Heading]]
[[Note|alias]]
![[Note#Heading]]
```

## Callouts

```md
> [!tip] Title
> Body of the callout.
```

Put `+` or `-` after the type to expand or collapse it: `> [!note]- Title`.

## Tasks and embeds

```md
- [ ] Open task
- [x] Done

![[diagram.png]]
```

## Standard Markdown still works

Headings, lists, tables, fenced code, and footnotes behave like GitHub Flavored Markdown unless a plugin changes them.
