# MarkdownTools

Browser-based Markdown toolkit: editor, converters, generators, cheat sheets, and syntax guides.

The published site is [https://WangLaoShi.github.io/MarkdownTools/](https://WangLaoShi.github.io/MarkdownTools/).

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Document text stays in the browser. GitHub Pages serves the static export, so fetching arbitrary URLs and probing remote links are not available there.
